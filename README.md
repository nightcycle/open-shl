# superhero-life

## Getting Started

### ENV Variables

Set the following env variables, I recommend using the "Secrets" plugin to manage them specifically for this project. It is configured to auto-open a folder called "superhero-life"
- `RUN_ROBLOX_API_KEY`: used publishing and luau execution during the run script
- `RUN_PLACE_ID`: the place id for remotely running the code
- `RUN_UNIVERSE_ID`: the universe id for remotely running the code
- `ASPHALT_API_KEY`: the key used for uploading cloud assets like animations / images / sounds
